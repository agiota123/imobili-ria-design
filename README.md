# Imobiliária Design

Crie apenas a estrutura técnica mínima de um projeto React + TypeScript + Vite para servir de base para desenvolvimento posterior.



Requisitos:



- Uma única página inicial com o texto "Projeto inicial".

- Apenas os arquivos essenciais para o projeto funcionar.

- Não crie design elaborado, landing page, imagens, animações, componentes extras, banco de dados, autenticação ou integrações.

- Não instale dependências desnecessárias.

- Preserve a estrutura padrão e mantenha o código simples e funcional.

- Não implemente nenhuma funcionalidade além dessa base inicial.



O objetivo é apenas preparar o código para ser sincronizado com um repositório GitHub e posteriormente desenvolvido manualmente. Priorize a menor quantidade possível de alterações e consumo de créditos. Utilize menos de 1 crédito
